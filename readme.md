# 🎂 Age Calculator

A simple and responsive **Age Calculator** built using **HTML, CSS, and JavaScript**. It calculates a user's exact age in **Years, Months, and Days** based on their date of birth.

![Age Calculator Screenshot](screenshot.png)

## 🚀 Features

- 📅 Select your Date of Birth
- 🧮 Calculates exact age in:
  - Years
  - Months
  - Days
- ⚡ Instant calculation
- 📱 Responsive design
- 🎨 Clean and simple user interface

## 💻 How to Run

1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Age_calculator.git
```

2. Open the project folder.

3. Double-click **index.html**
   or open it in your browser.

---

## 📖 How It Works

1. Select your birth date.
2. Click the **Calculate Age** button.
3. The application displays your age in **Years, Months, and Days**.
